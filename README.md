# hxyfront-62011 马术蹄铁修整档案

面向马术俱乐部蹄铁师的逐马修整档案应用：四蹄分别记录蹄形与磨耗，异常蹄写清问题；复查到期自动提醒，完成复查即移出入待办；历史记录可逐蹄对比变化与蹄铁/钉位改动。数据全部保存在本机浏览器 localStorage，新增、复查、补照片备注后重新打开仍在，且严格按马匹隔离。

## 功能

- **马匹列表**：编号唯一校验、用途分类（运动马/休养马）、按编号或马名搜索；每匹马实时同步「到期数 / 待复查数 / 异常」标记，支持前蹄、后蹄异常筛选。
- **四蹄分蹄记录**：左前、右前、左后、右后各自填写蹄形评估、磨耗情况、蹄铁类型、钉位；勾选异常时必须写清问题描述（含蹄位），正常蹄保存时按蹄位归档提示。
- **复查提醒**：下一复查日到期（含逾期）进入待办列表，另列出 7 天内即将到期；完成复查后旧记录标记完成、从待办移走，同时生成一条新修整记录。
- **历史对比**：每次修整自动与同马上一次记录逐蹄对比——蹄形、磨耗变化、新异常/异常解除，以及蹄铁类型与钉位改动；首次记录提示无对比基线。
- **照片与备注**：支持拍照/选图（自动压缩为 JPEG 存入本地），可加照片备注；复查后可向历史记录追加照片与备注。
- **本地持久化**：所有数据存于 localStorage（键 `farrier-archive-v1`），每条记录带 `horseId`，详情仅按当前马 id 过滤，不会串马。

## 技术栈

React 19 + Vite 7 + TypeScript（严格模式），无后端、无额外运行时依赖。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62011。构建：`npm run build`。
